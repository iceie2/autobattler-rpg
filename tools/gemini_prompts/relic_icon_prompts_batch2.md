# Relic icon prompts — batch 2 (46 new relics, pool 55→101)

Same proven style as batch 1 (the 29-relic pass): rounded-square frame tinted to grade
color, dark near-black backdrop, single bold pixel-art emblem, no text. 4-column × 2-row
grid, unused cells left empty so the Gemini watermark (bottom-right) never overlaps art.

Grade colors: D = #A6A6AD grey · C = #33A047 green · B = #4C8CF2 blue · A = #AD59F2 purple · S = #FFD900 gold.

Style block (reused verbatim, swap the emblem list per sheet):
> A set of [N] square game relic icons, 256x256 each, in a chunky pixel-art fantasy style: bold pixel clusters, limited flat color palette, hard pixel edges, no anti-aliasing blur, no gradients. Each icon is a self-contained tile: a rounded-square border frame in the color specified below, enclosing a dark near-black backdrop, with a single bold emblem centered and filling about 70% of the tile. No text, letters, numbers, or labels anywhere. Readable at small size (reads clearly at 48x48). Arrange the icons in a strict 4-column × 2-row grid with uniform gutters between tiles — any unused cells must be left as flat solid backdrop with no border and no emblem, completely empty.

Save each generated sheet, then crop cells in reading order (left→right, top→bottom) to
`assets/icons/Relics/<id>.png` per the mapping under each sheet.
